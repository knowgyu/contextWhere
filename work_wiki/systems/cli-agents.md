# CLI Agents

CLI agents include Codex/OMX/Claude Code-style sessions used for coding, research, planning, verification, and repo maintenance.

## Desired role in contextWhere

Each meaningful session should produce a durable summary with:

- goal
- constraints
- decisions
- changed files
- verification evidence
- unresolved risks
- follow-ups

Stable lessons should be promoted into `procedures/`, `decisions/`, or `systems/` pages.
