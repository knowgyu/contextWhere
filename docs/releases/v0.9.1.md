# v0.9.1 — OfficeWhere daily ingest opt-in

## 요약

0.9.1은 자동 daily run에서 OfficeWhere 문서 검색을 기본으로 수행하지 않도록 바꾼다.

## 변경 사항

- `contextwhere daily`는 MailWhere ingest만 기본 실행한다.
- OfficeWhere는 `--officewhere-query`가 있을 때만 검색한다.
- 기본 daily 결과에는 OfficeWhere `status:"skipped"`가 기록된다.
- 문서/운영 가이드는 OfficeWhere를 full-corpus mirror가 아니라 mail/file link evidence 대상으로 설명한다.

## 검증

- `python -m compileall -q src tests`
- `pytest -q`
- `npx --yes pyright src tests`
- `python -m contextwhere verify --json`
- daily default OfficeWhere skip
- daily OfficeWhere explicit opt-in unavailable path
