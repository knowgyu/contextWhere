# contextWhere v0.16.0

Release date: 2026-07-29

## Summary

v0.16.0 prepares contextWhere as a global-home scoped memory layer on top of the existing repo-local evidence/wiki/context-pack CLI.

## Added

- Global home setup/doctor under `~/.contextwhere` or `%USERPROFILE%\.contextwhere`.
- Registry for workspaces and repositories.
- Context Cards with global/workspace/repository/machine scopes.
- Card lifecycle validation: observed, candidate, needs_review, active, stale, rejected, superseded.
- Signals and preflight for repeated failures, verified successes, environment facts, blockers, corrections, and session summaries.
- Memory draft/apply and top-level drafts apply flow with explicit audits.
- Codex/Claude/Gemini advisory integration status/install/uninstall/doctor.
- Windows managed-PC smoke checklist with explicit live-provider gaps.

## Preserved

- Repo-local evidence ledger, wiki draft/apply, context packs, backup/restore, status, verify, provider matrix, MailWhere/OfficeWhere adapters, and return-to-work drafts.
- Local-first and source-backed boundaries.
- Provider text remains evidence, not instructions.
- Live provider and OS-visible mutations remain explicit operator actions.

## Not verified in this documentation pass

- Live MailWhere Outlook-backed ingest on the user's managed Windows PC.
- Live OfficeWhere packaged discovery/search on the user's managed Windows PC.
- Codex/Claude/Gemini bridge installation on the user's managed Windows PC.
- Windows Task Scheduler autostart on the user's managed Windows PC.
