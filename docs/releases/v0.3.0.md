# v0.3.0 — agent JSON tool gateway

## 요약

0.3.0은 외부 agent가 contextWhere를 안정적으로 호출할 수 있는 JSON tool gateway를 추가한다. 정식 MCP 서버 전 단계로, shell/CLI 환경에서 manifest를 읽고 등록된 tool을 JSON object 입력으로 호출한다.

## 변경 사항

- `contextwhere tools manifest --json` 추가.
- `contextwhere tools call <tool_name> --input-json ... --json` 추가.
- 등록 tool:
  - `query_evidence`
  - `capture_session`
  - `entities_extract`
  - `entities_list`
  - `relationships_list`
- tool gateway tests 추가.
- README/운영/제품 문서에 agent tool gateway 설명 추가.

## 안전 경계

- JSON object 입력만 허용한다.
- 알 수 없는 tool은 실패한다.
- Provider mutation, OS-visible open/reply/delete/reindex action은 제공하지 않는다.
- Query/list 계열은 read-only다.
- Capture/extract 계열은 project-owned SQLite evidence/metadata만 갱신한다.

## 검증

- 장기 실행 daemon, auth, multi-user policy는 후속 0.3.x/1.0 범위다.
