# v0.2.0 — deterministic entity extraction and relationship seed

## 요약

0.2.0은 evidence ledger 위에 첫 graph/memory seed를 추가한다. LLM 요약이나 raw provider payload 없이, 이미 sanitize된 evidence 텍스트에서 deterministic entity 후보를 추출하고 SQLite relationship table에 연결한다.

## 변경 사항

- `entities`, `evidence_entities`, `relationships` tables 추가.
- `contextwhere entities extract --json` 추가.
- `contextwhere entities list --json` 추가.
- `contextwhere entities relationships --json` 추가.
- `contextwhere verify --json` smoke에 entity extraction 단계 추가.
- README/운영/제품 문서에 0.2.0 graph seed 설명 추가.

## 안전 경계

- Entity extraction은 provider text를 실행하지 않는다.
- Wiki를 자동 수정하지 않는다.
- 이미 sanitize되어 evidence DB에 저장된 title/snippet/summary/provenance 중심으로만 후보를 만든다.
- Relationship은 0.2.0에서 `co_occurs_with` seed이며, 장기 사실로 승격하려면 별도 wiki draft/apply workflow가 필요하다.

- 0.2.0 extractor는 deterministic seed이므로 사람/조직/결정/작업의 정교한 canonicalization은 아직 제한적이다.
- 실제 업무 graph 승격은 후속 0.2.x에서 wiki draft/apply 정책과 함께 확장해야 한다.
