# v0.8.0 — unattended daily runner

## 요약

0.8.0은 설치 후 매일 손으로 여러 CLI 명령을 묶지 않도록 `contextwhere daily`를 추가한다.

## 변경 사항

- `contextwhere daily --json` 추가.
- daily run은 init, MailWhere/OfficeWhere read-only ingest, entity extraction, wiki draft, lint, status를 순서대로 실행한다.
- Provider unavailable 상태는 safe structured result로 기록하고 계속 진행한다.
- Wiki draft는 생성하지만 자동 apply하지 않는다.
- 설치 문서에 `pipx` / `uv tool` 설치 경로를 추가했다.

## 검증

- `python -m compileall -q src tests`
- `pytest -q`
- `npx --yes pyright src tests`
- `python -m contextwhere verify --json`
- `contextwhere daily --json` unavailable-provider safe path
