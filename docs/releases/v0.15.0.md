# contextWhere v0.15.0

Makes Windows 11 the primary setup target and adds a bounded return-to-work evidence workflow while keeping Ubuntu supported.

## Changed

- Added `docs/WINDOWS.md` with PowerShell-first install, development, autostart, and routine command examples.
- Rewrote install and schedule docs around Windows 11 first, Ubuntu second.
- Locked Windows Task Scheduler autostart planning with tests.
- Added deterministic `return-to-work ingest|brief` drafts over MailWhere export JSON, pasted text, and explicit `.txt`/`.md` documents.
- Kept imported text inert, defaulted to locator/hash retention, rejected unsafe manifests before writes, and preserved idempotent rerun provenance.
- Clarified the product split: MailWhere owns mail mirror/search, OfficeWhere owns document indexing/search, and contextWhere owns cross-provider evidence/wiki/context packs.
- Marked the standalone `where-skills` wrapper as an archive candidate, not safe to delete until the OfficeWhere dynamic-port discovery decision is complete.

## Verification

- 68 clean-HEAD Python tests passed.
- `contextwhere verify --json` passed all 13 smoke steps.
- Live provider failures remain structured and non-fatal.
