# contextWhere v0.15.1

Removes the last runtime reason to keep the standalone `where-skills` wrapper active.

## Changed

- Discover packaged OfficeWhere through the user-scoped `provider-discovery.json`.
- Prefer LocalAppData over legacy Roaming on Windows and use the native Electron user-data location on macOS/Linux.
- Reject malformed, wrong-provider, wrong-contract, and non-loopback discovery entries.
- Fall back to the next candidate or development loopback URL when discovery is absent or stale.
- Preserve explicit `OFFICEWHERE_BASE_URL` and `--officewhere-base-url` overrides.

## Verification

- 70 Python tests passed, including OfficeWhere discovery and stale fallback.
- `contextwhere verify --json` passed all 13 smoke steps.

## Still external

- Real packaged OfficeWhere and MailWhere calls on the managed Windows PC.
