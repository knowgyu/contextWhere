# contextWhere v0.11.0

Scope-first workspace context OS slice.

## Added

- Scoped context pack command: `contextwhere context pack` emits JSON or Markdown with manifest, evidence IDs, source locators, inclusion reasons, and omitted-context reasons.
- Tenant/scope/source locator vocabulary stored in existing evidence metadata for v0.11 compatibility.
- Stale/superseded/sensitivity filtering before context-pack inclusion.
- Workspace provider matrix entries for agent sessions, repo-state, git, GitHub, Jenkins/deploy, MailWhere, OfficeWhere, and manual/wiki.
- Local read-only capture: `contextwhere capture-local --git --omx` imports git status/log and repo-local `.omx` context/plan files as scoped evidence.

## Safety

- No graph/vector dependency.
- Git capture uses read-only status/log only.
- OfficeWhere remains explicit/selective; no full-corpus sweep.
- Provider text remains evidence, not instructions.
