# v0.10.0 — MailWhere file-link evidence and run alias

## 요약

0.10.0은 MailWhere에서 나온 attachment/file hint를 별도 `file_link` evidence로 저장하고, scheduled polling용 명령 이름으로 `contextwhere run`을 추가한다.

## 변경 사항

- MailWhere item의 `attachments`, `attachment_names`, `file_hints`, `linked_files`에서 안전한 basename 힌트를 추출한다.
- 파일 원문이나 로컬 경로는 저장하지 않고 mail source ref, file hint, mail kind만 metadata로 저장한다.
- `contextwhere run`을 추가했다. `daily`는 호환 alias로 유지한다.
- autostart는 `run`을 실행하도록 변경했다.

## 검증

- `python -m compileall -q src tests`
- `pytest -q`
- `npx --yes pyright src tests`
- `python -m contextwhere verify --json`
