# v0.1.1 — Korean README and operational verification foundation

## 요약

0.1.1은 0.1.0의 safe provider ingest foundation 위에 운영 반복성을 추가한 릴리즈다.

## 변경 사항

- README를 한국어 중심으로 재작성하고 최종 goal 생성 시점의 목표/상태를 반영했다.
- `contextwhere verify --json` 명령을 추가해 설치 후 로컬 smoke를 바로 검증할 수 있게 했다.
- cron/systemd 운영 스케줄 예제를 추가했다.
- 설치/운영/제품/릴리즈 문서를 0.1.1 기준으로 갱신했다.
- verify 명령 테스트와 pyright-clean 타입 보증을 추가했다.

## 검증

- `python -m compileall -q src tests`
- `pytest -q` → 25 passed
- `python -m contextwhere verify --json` → ok true
- `npx --yes pyright src tests` → 0 errors, 0 warnings
- temp-root smoke: init, provider health, fixture ingest, query, wiki draft/apply, lint, capture-session, verify

## 남은 리스크

- live MailWhere/OfficeWhere 환경은 이 Linux 검증 환경에서 직접 연결하지 못했다.
- systemd/cron 예제는 템플릿이므로 설치 경로와 사용자명을 운영 환경에 맞게 수정해야 한다.
