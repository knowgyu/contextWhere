# v0.4.0 — local recall bundles

## 요약

0.4.0은 외부 embedding/vector API 없이, SQLite evidence query 결과를 재현 가능한 local recall bundle로 저장하는 기능을 추가한다.

## 변경 사항

- `recall_bundles` table 추가.
- `contextwhere recall create --name ... --query ... --json` 추가.
- `contextwhere recall list --json` 추가.
- `contextwhere recall show <bundle_id> --json` 추가.
- JSON tool gateway에 `recall_create`, `recall_list`, `recall_show` 등록.
- `contextwhere verify --json` smoke에 recall bundle 단계 추가.

## 안전 경계

- Raw provider payload나 원문 문서를 복사하지 않는다.
- Bundle에는 query/search mode/limit/evidence id 목록만 저장한다.
- `show`는 현재 SQLite evidence row를 evidence id 순서대로 조회한다.
- 외부 embedding/API/network 호출은 없다.

## 검증

- `python -m compileall -q src tests`
- `pytest -q` → 35 passed
- `python -m contextwhere verify --json` → ok true, includes `recall-bundle`
- `npx --yes pyright src tests` → 0 errors, 0 warnings

## 남은 리스크

- Semantic/vector recall은 아직 구현하지 않았다.
- Bundle refresh/diff 정책은 후속 0.4.x에서 정교화해야 한다.
