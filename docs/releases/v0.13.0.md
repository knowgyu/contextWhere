# contextWhere v0.13.0

Adds direct local evidence inspection for source-backed context packs.

## Added
- `contextwhere evidence show <evidence_id>` returns one sanitized evidence row and parsed metadata.
- `contextwhere evidence show --source-locator <locator>` resolves exact source locator metadata.
- Verify smoke now checks evidence lookup.
