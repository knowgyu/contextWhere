# contextWhere v0.12.0

Adds a minimal routine maintenance command after v0.11 scope-first packs.

## Added
- `contextwhere maintain` initializes local storage, captures `.omx`/git evidence, builds a scoped context pack, runs wiki lint/status, and emits a JSON step summary.
- Missing `work_wiki`, `.git`, or `.omx` is safe; missing wiki is a warning, not implicit content creation.
- `--strict-git` returns non-zero when git capture reports unavailable.
