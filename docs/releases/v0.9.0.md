# v0.9.0 — user-level autostart installer

## 요약

0.9.0은 사용자가 매번 `contextwhere daily`를 직접 실행하지 않아도 되도록 `contextwhere autostart`를 추가한다.

## 변경 사항

- `contextwhere autostart plan --json` 추가.
- `contextwhere autostart install` 추가.
- Linux는 user-level systemd timer를 생성한다.
- Windows는 Task Scheduler 등록 명령을 사용한다.
- `install`은 `--yes`가 없으면 Y/N 확인을 요구한다.
- 자체 daemon은 추가하지 않는다.

## 검증

- `python -m compileall -q src tests`
- `pytest -q`
- `npx --yes pyright src tests`
- `python -m contextwhere verify --json`
- `contextwhere autostart plan --json`
- noninteractive `autostart install` confirmation gate
