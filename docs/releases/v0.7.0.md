# v0.7.0 — provider compatibility matrix

## 요약

0.7.0은 배포 환경에서 live provider를 연결하기 전에 MailWhere와 OfficeWhere가 어떤 transport, 설정, 안전 경계로 동작하는지 확인할 수 있는 static JSON matrix를 추가한다.

## 변경 사항

- `contextwhere providers matrix --json` 추가.
- MailWhere/OfficeWhere transport, live requirement, optional config, ingest kinds를 문서화한다.
- Provider별 read-only promise, blocked mutating actions, safety boundaries를 CLI-readable JSON으로 고정한다.
- README, 설치, 운영, 제품 문서에 matrix 사용법을 추가한다.

## 안전 경계

- Matrix는 static/read-only이며 live provider probing이나 OS-visible action을 하지 않는다.
- Provider health와 달리 missing command/server 때문에 실패하지 않는다.
- Mutating action list는 빈 배열로 유지해 현재 릴리즈의 no-open/no-reply/no-delete/no-reindex 원칙을 명확히 한다.

## 검증

- `python -m compileall -q src tests`
- `pytest -q` → 42 passed
- `npx --yes pyright src tests` → 0 errors, 0 warnings
- `contextwhere providers matrix --json` smoke → ok true, format `contextwhere-provider-matrix-v1`

## 남은 리스크

- Provider별 버전 감지와 live compatibility scoring은 후속 0.7.x 또는 1.0 hardening에서 추가해야 한다.
- Matrix format backward compatibility policy는 1.0 전에 고정해야 한다.
